# Sprint 6 — Тестирование сервиса «Яндекс Самокат»

## Описание проекта

Проект посвящён автоматизации тестирования сервиса «Яндекс Самокат»

В проекте используются:

 Python
 Pytest
 Selenium WebDriver
 Page Object Model
 Allure Report

Автоматизированы проверки основного функционала главной страницы, формы заказа и ссылок на логотипах

## Установка

Клонировать репозиторий:

git clone git@github.com:SnChalov/Sprint_6.git

Перейти в директорию проекта:

cd Sprint_6

Создать виртуальное окружение:

python -m venv .venv

Активировать виртуальное окружение в PowerShell:

.venv\Scripts\Activate.ps1

Установить зависимости:

pip install -r requirements.txt

## Запуск тестов

python -m pytest -v


## Allure

Для формирования результатов тестирования используется Allure

Запустить тесты с сохранением результатов для Allure:

python -m pytest --alluredir=allure-results

Сгенерировать отчёт:

allure generate allure-results -o allure-report --clean

Открыть отчёт в браузере:

allure open allure-report

## Автоматизированные тесты

### FAQ

Проверяется:

открытие каждого вопроса в разделе «Вопросы о важном»
соответствие отображаемого ответа ожидаемому тексту

Всего реализовано 8 тестов.

### Логотипы

Проверяется:

переход на главную страницу при нажатии на логотип «Самокат»
переход на страницу Дзена при нажатии на логотип «Яндекс»

Всего реализовано 2 теста

### Оформление заказа

Проверяется оформление заказа через обе кнопки «Заказать»

В тестах используются разные данные:

имя и фамилия
адрес
станция метро
номер телефона
дата доставки
срок аренды
цвет самоката
комментарий для курьера

Всего реализовано 2 теста

## Page Object Model

Для разделения тестовой логики и взаимодействия с элементами страницы используется паттерн Page Object

### MainPage

Содержит методы для работы с главной страницей:

закрытие уведомления о cookies
нажатие кнопок «Заказать»
работа с разделом FAQ
переход по логотипу «Самокат»
переход по логотипу «Яндекс»

### OrderPage

Содержит методы для работы со страницами оформления заказа:

заполнение данных пользователя
выбор станции метро
переход между страницами заказа
выбор даты доставки
выбор срока аренды
выбор цвета самоката
ввод комментария
оформление и подтверждение заказа
проверка успешного оформления заказа
